# Railway Environment Variables Template

Copy and paste these environment variables into Railway for each service.

## 🔧 Backend Service Variables

```env
PORT=5000
NODE_ENV=production
FINNHUB_API_KEY=paste_your_finnhub_api_key_here
CORS_ORIGIN=*
```

**After deploying frontend, update:**
```env
CORS_ORIGIN=https://your-frontend-url.up.railway.app
```

---

## 🎨 Frontend Service Variables

```env
NODE_ENV=production
REACT_APP_API_URL=https://your-backend-url.up.railway.app/api
```

⚠️ **Important:** Replace `your-backend-url.up.railway.app` with your actual backend URL!

---

## 📝 How to Get API Keys

### Finnhub API Key (Required for Stocks)
1. Go to https://finnhub.io/register
2. Sign up for free account
3. Copy your API key from dashboard
4. Paste into `FINNHUB_API_KEY` variable

**Note:** CoinGecko and ExchangeRate APIs don't require keys!

## 🔍 Quick Check

**Backend Variables Checklist:**
- [ ] `PORT=5000`
- [ ] `NODE_ENV=production`
- [ ] `FINNHUB_API_KEY=<your_actual_key>`
- [ ] `CORS_ORIGIN=<your_frontend_url>` (or `*` initially)

**Frontend Variables Checklist:**
- [ ] `NODE_ENV=production`
- [ ] `REACT_APP_API_URL=<your_backend_url>/api` (must include `/api`)

---

## ⚠️ Common Mistakes

❌ **Wrong:** `REACT_APP_API_URL=https://backend.railway.app`
✅ **Correct:** `REACT_APP_API_URL=https://backend.railway.app/api`

❌ **Wrong:** Using localhost URLs in production
✅ **Correct:** Using Railway-generated URLs

❌ **Wrong:** Forgetting to redeploy after changing env vars
✅ **Correct:** Railway auto-redeploys, but frontend needs rebuild

---

**Pro Tip:** Set `CORS_ORIGIN=*` initially, then update to your specific frontend URL once deployed for better security.
